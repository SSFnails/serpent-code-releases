# Serpent Code — загрузки

Здесь лежат только установочные файлы Serpent Code — приложения SerpentAI для работы с файлами и кодом на компьютере. Исходного кода здесь нет.

Сайт и аккаунт: https://serpentai.io · страница загрузки: https://serpentai.io/code

Файлы — в разделе [Releases](https://github.com/SSFnails/serpent-code-releases/releases/latest). Рядом с каждым файлом лежит `.sha256` с контрольной суммой.

## Установка на Mac (Apple M1 и новее)

1. Скачайте `SerpentCode-<версия>-mac-arm64.zip` и откройте его — появится `SerpentAI.app`.
2. Перетащите `SerpentAI.app` в папку «Программы».
3. Приложение пока без подписи Apple, поэтому первый запуск такой:
   - macOS 14: правый клик по SerpentAI → «Открыть» → «Открыть».
   - macOS 15 и новее: запустите один раз, затем «Системные настройки» → «Конфиденциальность и безопасность» → «Всё равно открыть».
4. Дальше приложение открывается как обычно.

## Установка на Windows 10 и 11 (64-бит)

1. Скачайте `SerpentCode-<версия>-win-x64.exe` и запустите.
2. Если появится окно SmartScreen: «Подробнее» → «Выполнить в любом случае».

## Проверка файла (по желанию)

- Mac: `shasum -a 256 SerpentCode-<версия>-mac-arm64.zip`
- Windows: `Get-FileHash SerpentCode-<версия>-win-x64.exe`

Сумма должна совпасть с файлом `.sha256` из того же выпуска.

## Обновления

Новая версия появляется здесь и на https://serpentai.io/code. Установите её поверх старой — задачи и настройки сохранятся.
